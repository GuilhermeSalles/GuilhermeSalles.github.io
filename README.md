# Guilherme Baltazar — Portfólio

Portfólio pessoal de **Guilherme Baltazar**, Engenheiro de Software focado em Java (Spring Boot/Batch), Node.js e arquiteturas de alta escalabilidade. O site apresenta a trajetória profissional, stack técnica e uma vitrine de projetos.

🔗 **Online:** [guilhermesalles.github.io](https://guilhermesalles.github.io/)

---

## ✨ Funcionalidades

- **Bilíngue (PT/EN)** — troca de idioma em tempo real via atributos `data-pt` / `data-en`.
- **Design moderno** — tema escuro, efeito _glassmorphism_, spotlight que segue o cursor e overlay de ruído.
- **Animações on-scroll** — revelação de elementos com [ScrollReveal](https://scrollrevealjs.org/), barra de progresso de scroll e botão "voltar ao topo".
- **Hero interativo** — orbs animados, revelação do título palavra por palavra e contadores animados.
- **Responsivo** — navegação com _drawer_ full-screen no mobile.
- **SEO & compartilhamento** — meta tags Open Graph, Twitter Cards e canonical.

## 🚀 Como executar localmente

Por ser um site estático, basta abrir o `index.html` no navegador. Para melhor experiência (evitando restrições de CORS), use um servidor local:

```bash
# Com Python
python -m http.server 8000

# Ou com Node
npx serve
```

Acesse `http://localhost:8000`.
