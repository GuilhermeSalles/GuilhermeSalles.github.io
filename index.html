01. Perfil

Arquitetura primeiro. Código depois.

Sou Guilherme Baltazar, bacharel em Ciência da Computação com mais de 7 anos construindo o backbone de sistemas críticos. Minha trajetória foi de evolução rápida: pulei o nível júnior por desempenho técnico e hoje atuo como Desenvolvedor Pleno em uma multinacional, como responsável técnico de um sistema governamental de alto volume.

Meu trabalho começa antes do código: desenho a arquitetura, mapeio riscos e pontos de performance a partir do requisito e só então implemento. Na prática, isso reduz retrabalho, encurta o ciclo de entrega e mantém o sistema estável em produção.

Uso IA generativa como acelerador, mas com governança: eu defino a arquitetura, os contratos e os padrões de qualidade, e a IA gera código dentro desse contrato — nunca o contrário. Tudo que sai daí passa por revisão, teste e leitura crítica antes de chegar em produção.

"Penso como dono: me coloco no lugar de quem vai conviver com o sistema, antecipo onde ele vai doer e construo para isso — não para fechar o ticket."

02. Sistema

Como eu monto um backend.

client Web · Mobile HTTPS
edge API Gateway Spring Security · JWT
service Serviço de Domínio Java 17 · Spring Boot
service Rotinas Batch Spring Batch
broker Apache Kafka eventos · offsets
data PostgreSQL · Oracle Spring Data · JPA
delivery CI/CD · Observabilidade GitLab CI · Kibana
Passo 00 · Requisito Antes de qualquer código, o terreno: o que o sistema precisa aguentar, onde ele pode quebrar e quanto custa errar.
Passo 01 · Fronteira Quem consome define o contrato. Web e mobile entram pelo mesmo acordo explícito, versionado e testado.
Passo 02 · Porta de entrada Autenticação, autorização e limites ficam na borda — nenhum serviço de domínio precisa saber como você entrou.
Passo 03 · Domínio Serviços pequenos, com responsabilidade única e código legível. O que roda em lote fica separado do que responde em tempo real.
Passo 04 · Desacoplamento Eventos no lugar de chamadas diretas. Um consumidor pode cair que o broker segura a fila e o offset retoma de onde parou.
Passo 05 · Persistência O dado é o ativo. Modelagem, índices e queries sob medida — performance aqui é a diferença entre segundos e horas.
Passo 06 · Produção Nada existe até estar em produção e observável. Pipeline, logs e métricas fecham o ciclo — e é aqui que a arquitetura prova que estava certa.
